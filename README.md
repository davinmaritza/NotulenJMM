# NotulenJMM

Knowledge-driven system and repository for **NotulenJMM**.

## Overview
This repository serves as the **Single Source of Truth** for the actual implementation, codebase, tests, and configuration of the NotulenJMM project. High-level architecture, decisions, meeting records, roadmap, and operational knowledge are managed and synchronized through the integrated Notion Knowledge System.

## Knowledge System Integration
- **Implementation State**: Repository (`main` branch)
- **Project Knowledge Base**: Notion (`NotulenJMM` Root Page)
- **Agent Rules & Context Management**: `.claude/CLAUDE.md`

## Workflow
All engineering operations follow the strict sequence:
```
Read Context → Inspect Repository → Understand Task → Plan → Implement → Validate → Update Knowledge → Sync Notion → Update Context
```
